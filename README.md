## Task 1: Iris Dataset Visualization

### Objective
Load, explore and visualize the Iris dataset to understand data trends.

### Dataset
Iris Dataset (loaded via seaborn library)

### Libraries Used
- pandas
- seaborn
- matplotlib

### What I Did
- Loaded dataset and checked shape, columns, statistics
- Created Scatter Plot, Histograms and Box Plots

### Key Results
- Dataset has 150 samples and 5 columns
- 3 species: setosa, versicolor, virginica (50 each)
- Petal length is best feature to distinguish species
